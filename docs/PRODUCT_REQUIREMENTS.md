# 현재 제품 목표

원래 목표는 음악 앱의 PCM을 앱 컨테이너에서 받아, 호스트에서 안정적으로 출력하는 가상 DAP다.
단일 테스트 통과나 앱의 시작 콜백을 전체 목표 달성으로 취급하지 않는다.

## 최신 사용자 결정

- Android 14(API 34) 이상, 루팅·특정 휴대폰 허용 목록·별도 Android OS 부팅 없이 설치/설정한다.
- 음악 앱이 주 화면이다. 최종 사용자 UI는 한국어로 제공한다.
- USB/이어폰 미연결 상태에서도 음악 앱 실행과 앱 내부 설정을 허용한다. 오디오 준비는 별도이며,
  출력 없는 실행에 알림/USB 권한이나 오디오 서비스 시작을 요구하지 않는다.
- 진단, 출력 소리 테스트, 로컬 DSD 파일은 작은 하나의 도구 메뉴로 모은다.
- 기본 출력은 직접 USB 오디오다. 공식 API의 선택적 비트퍼펙트 지원에 의존하지 않는다.
- 공식 비트퍼펙트 API 경로는 별도 고급 모드로 제공한다.
- 두 모드 사이 또는 Android 일반 믹서/스피커로 자동 대체하지 않는다.
- USB 모드도 원본 포맷을 우선 협상한다. 리샘플링·채널 변환·정수 변환·음량 조절이 있는
  재생을 비트퍼펙트로 표시하지 않는다. DoP/네이티브 DSD에는 PCM 변환과 음량 처리를 섞지 않는다.
- 실제 사용 가능한 범위를 검증한 뒤 서명된 다운로드 APK를 GitHub Release로 제공한다.
- 단계별로 `sampple-korea` 작성자 커밋과 원격 푸시를 한다.

## 실제 사용자 제보

SM-S938N + Moondrop FreeDSP에서 기존 빌드의 공식 경로가 `Unsupported on this device`로
표시되었다. USB 연결 여부와 공식 mixer attribute 지원 여부는 별개다. 이전 구현은 API 조회
실패와 지원 포맷 부재도 구분하지 않았다. 이 제보만으로 FreeDSP의 직접 USB 지원 또는 미지원을
단정하지 않는다. 중복 휴대폰 이름은 출력 유형/경로 ID를 함께 표시해 구분한다.

## 최종 완료 범위 — 2026-09-17 사용자 변경

사용자는 음악 서비스 로그인 호환성과 음악 앱 내부 재생 검증을 이번 완료 조건에서 제외했다.
남은 범위는 코드 오류 수정, UI·UX·인터페이스 정리, 참고 앱과 비교한 관련 기능 점검 및 배포다.
이 결정은 기존 로그인/재생 문제의 해결 또는 모든 앱·DAC 호환 인증을 뜻하지 않는다.
검증 제외 항목을 반복 재현하거나 이를 이유로 완료를 무기한 미루지 않는다.

## 완료 증거

- 기본 USB 권한/협상/수명/오류/볼륨/분리 처리와 고급 모드의 엄격한 계약에 대한 테스트.
- 한국어 앱 중심 탐색, 메뉴 접근, 실패 후 복구의 실제 실행 확인.
- 컨테이너 설치/업데이트/삭제 및 오디오 계약은 독립 테스트 앱과 자동화로 검증한다.
  상용 앱 로그인·앱 내부 재생은 범위 밖이며 성공으로 표시하지 않는다.
- 배포 커밋의 빌드·lint·단위·Android 14/16 테스트 및 APK ABI/서명/라이선스 검증.
- 소프트웨어 검증과 물리 DAC 출력 측정을 구분한 릴리즈 노트, APK와 체크섬.

물리 기기/DAC 검증은 사용자가 면제했다. 계정·구독·DRM·무결성 결과를 위조하거나 독점 코드를
복사하는 방식은 사용하지 않는다. 필요한 오픈소스 라이선스는 배포물에도 유지한다.
