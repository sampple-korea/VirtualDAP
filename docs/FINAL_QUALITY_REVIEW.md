# 최종 코드·사용성 점검

2026-09-17 사용자가 정한 완료 범위: 로그인·상용 앱 내부 재생 검증은 제외하고,
코드·UI·UX·인터페이스·관련 기능을 정리해 배포한다. 물리 DAC 검증도 제외한다.

## 기능 비교와 반영

참고 APK에서 확인한 제품 기능/구조와 공개 규격을 비교했다. 독점 코드를 복사하거나 이름만
바꿔 배포하지 않았다. 오픈소스 구성요소의 필수 라이선스와 출처는 유지한다.

| 영역 | 제품에 반영한 기능 / 이번 조치 |
| --- | --- |
| 앱 공간 관리 | APK/APKS 및 휴대폰 앱 가져오기, 분리된 데이터, 시작/중지, 업데이트 유지. 앱 검색과 확인 후 공간 내 삭제 추가. 원본 휴대폰 앱은 삭제하지 않음. |
| 의존 서비스 | 별도 도구에서 실제 설치 패키지 가져오기. 음악 카드와 구분. 인증 결과나 시스템 권한을 조작하지 않음. |
| 앱 수명 / IPC | 프로세스별 provider 초기화, 실제 Binder 호출자 정보, 서비스·브로드캐스트 전달, 초기화 오류 전파. 중복 실행 요청과 준비 중 표시 보완. |
| USB 출력 | 비루팅 권한/선택, UAC1/2, 클록 조회/설정/읽기 확인, 직접 등시 전송, 피드백·언더런·분리·취소 처리. |
| 고해상도 PCM | 원본 포맷 우선, 필요 시 명시적 레이트/채널/표현 변환. 변환 및 음량 변경 상태를 비트퍼펙트로 표시하지 않음. |
| DSD | DSF/비압축 DSDIFF, PCM 변환, DoP, 한정된 네이티브 레이아웃. 안전 확인과 재생/일시정지/중지. 진행 표시 및 적용되지 않는 음량 조작 안내 보완. |
| 조작 / 복구 | 한국어 음악 중심 2개 탭, 도구에 진단 통합, 출력 미선택 이유, 뒤로 가기로 음악 화면 복귀, 복사 가능한 오류. 소리 테스트 진행/완료/중단/실패를 같은 창에 표시. |

## 의도적으로 동일하게 만들지 않는 부분

- 별도 Android OS 부팅, 루팅·특정 휴대폰 종속 기능은 포함하지 않는다.
- 다중 계정 참고 앱의 전체 복제/무제한 공간 기능은 이 음악 전용 제품의 범위가 아니다.
- 일반 믹서/스피커 자동 대체, 인증 위조, 보호 콘텐츠 접근 우회는 추가하지 않는다.
- 크로스페이드/동시 출력, 임의의 vendor DSD 모드 전환, implicit-feedback DAC,
  DST 압축 DSDIFF 등 구현되지 않은 형식/전송은 지원한다고 표시하지 않는다.
- EQ 등 원본 변경 DSP를 일괄 추가하지 않는다. 원본 보존 여부는 실제 경로 조건으로 구분한다.

## 배포 검증

소스가 확정된 뒤 JVM/네이티브/생성 소스/린트/릴리즈 빌드와 APK 경계를 검증한다.
에뮬레이터는 릴리즈 직전 독립 테스트 앱과 UI/IPC/오디오 계약의 통합 검사에만 사용한다.
서명된 최종 APK의 버전·ABI·최소 API·정렬·서명을 확인하고 체크섬과 함께 배포한다.
실행 결과 및 릴리즈 커밋은 `RELEASE_READINESS.md`에 기록한다.

최종 커밋 `3f9509a`: JVM 149개, 생성 소스 30개, 네이티브 5개, 원격 Android 14/16 각 20개,
최종 서명 APK의 Android 16 검사 20개가 통과했다. 삭제 후 서비스 재연결 시 null 참조 오류를
발견해 수정했고, 비활성 버튼 검사는 텍스트가 아닌 실제 버튼 상태 및 동작을 확인한다.
빌드·린트 오류는 없으며 린트 경고 9개는 남아 있다. 배포 정보는 alpha.4 릴리즈 기록을 따른다.

자동 테스트 통과는 결함이 절대 없거나 실제 DAC/상용 로그인·재생이 보장된다는 뜻이 아니다.
