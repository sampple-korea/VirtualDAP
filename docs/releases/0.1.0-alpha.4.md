# VirtualDAP 0.1.0-alpha.4 — 앱 관리·사용성·컨테이너 안정화

Android 14 이상, 루팅 없이 설치하는 한국어 업데이트입니다. 이전 공개 알파와 같은 서명으로
업데이트할 수 있습니다. 요청하신 코드·UI·UX 정리 범위의 마감 배포이며, 모든 음악 서비스와
물리 DAC 호환성을 인증한 정식 안정판이라는 뜻은 아닙니다.

## 변경 사항

- 음악 앱 검색, 휴대폰 버전으로 업데이트, 확인 후 음악 공간 내 앱 삭제를 추가했습니다.
  삭제는 해당 공간의 앱 데이터에만 적용됩니다. 휴대폰 원본 앱은 유지됩니다.
- 앱 준비 중 표시와 중복 실행 방지를 추가하고, 실행 불가 시 필요한 조치를 안내합니다.
- 뒤로 가기로 출력 설정에서 음악 화면으로 돌아옵니다. 진단과 로컬 DSD는 도구 안에 유지합니다.
- 소리 테스트 창에 진행/완료/중단/실패와 오류를 표시합니다. 테스트 중 출력 장치 변경을 차단하고,
  장치 정리에 실패해도 테스트 실행 잠금이 풀리도록 수정했습니다.
- DoP/네이티브 DSD에서 적용되지 않는 USB 소프트웨어 음량 조작을 비활성화하고 안내합니다.
  DSD 선택 항목의 터치 영역과 진행 표시, 오류 텍스트 복사를 개선했습니다.
- 이전 alpha.3 이후 누적된 APK/split 가져오기, 서명 메타데이터, 서비스/provider/브로드캐스트,
  네트워크·Wi-Fi·미디어 호출자 정보, 초기화 실패 처리 수정이 포함됩니다.

## 설치와 사용

1. 기존 공개 알파 위에 업데이트 설치하세요. 서명이 다른 개발 APK는 업데이트되지 않을 수 있습니다.
   설치가 실패해도 먼저 기존 앱을 삭제하지 마세요. 삭제 시 음악 공간의 데이터가 사라집니다.
2. **오디오 출력 → USB 접근 허용 → 이 장치로 출력**을 선택합니다.
3. USB 음량은 기본 25%입니다. **도구 → 출력 소리 테스트**에서 낮은 음량으로 확인하세요.
4. **음악 앱**에서 APK/APKS 또는 휴대폰 앱을 추가하세요. 기존 계정 정보는 복사하지 않습니다.
5. 앱 카드의 관리 메뉴에서 업데이트/삭제할 수 있습니다. 삭제 확인 문구를 먼저 읽어 주세요.

## 범위와 제한

- 사용자의 최신 결정에 따라 상용 앱의 로그인 및 앱 내부 재생 검증은 이번 완료 조건에서 제외했습니다.
  기존 Apple/Google 서비스 로그인 문제를 해결 완료했다고 주장하지 않습니다.
- 물리 DAC와 SM-S938N·FreeDSP 실제 소리 출력은 검증하지 않았습니다.
- USB 기본/공식 비트퍼펙트 고급 모드는 명시적으로 선택합니다. 오류 시 스피커나 믹서로 자동 대체하지 않습니다.
- 변환·음량 조절이 있는 출력을 비트퍼펙트로 표시하지 않습니다. 동시에 하나의 출력 스트림을 지원합니다.
- DoP/네이티브 DSD에는 소프트웨어 음량이 적용되지 않습니다. DAC 지원과 하드웨어 음량을 확인하세요.
- implicit-feedback DAC, 임의 vendor DSD 전환, DST 압축 파일은 지원하지 않습니다.

APK 체크섬은 첨부 `SHA256SUMS`에서 확인할 수 있습니다. 문제 제보에 계정·비밀번호·토큰을 넣지 마세요.
