# VirtualDAP 0.1.0-alpha.5 — 연결 없이 앱 설정 · 음악 화면 개편

Android 14 이상에서 설치할 수 있는 업데이트입니다. 공개 alpha.1~4와 같은 서명입니다.

## 이번 변경

- USB DAC나 이어폰이 없어도 음악 앱을 열고 앱 안의 설정을 사용할 수 있습니다.
  실행 버튼과 컨테이너 내부의 출력 준비 조건을 분리했습니다.
- 출력이 없을 때 앱을 열면 오디오 서비스를 시작하거나 알림 권한을 먼저 요구하지 않습니다.
  단순 앱 설정을 위해 USB를 연결할 필요가 없습니다.
- 메인 화면을 '내 음악 공간'으로 개편했습니다. 실제 앱 아이콘과 간결한 목록, 검색,
  짧은 출력 상태 안내를 사용하고 반복되던 큰 카드·설명을 줄였습니다.
- 추가 버튼에서 휴대폰 앱 가져오기와 APK/APKS 선택을 한 번에 찾을 수 있습니다.
  앱 중지·업데이트·삭제는 각 앱의 관리 메뉴에 모았습니다.
- 어두운 배경과 민트 강조색, 일관된 카드·버튼·문자 크기로 정리했습니다.
  오류 상세는 펼쳐서 볼 수 있고, 진단·소리 테스트·DSD 도구는 메인과 분리해 유지합니다.
- 출력 설정에는 연결 순서와 별도 '출력 시작' 동작을 제공합니다.
  고급 모드의 내장 스피커·수화부 등 반복되는 미지원 항목은 진단으로 옮겼습니다.

## 사용 방법

1. 기존 공개 알파 위에 업데이트 설치하세요. 앱 삭제나 데이터 초기화는 필요하지 않습니다.
2. 음악 화면의 **+ → 휴대폰에서 가져오기 / APK 파일 선택**으로 앱을 추가합니다.
3. **앱 행을 누르면 연결 없이도 앱을 열 수 있습니다.** 앱 관리 메뉴는 오른쪽의 점 세 개입니다.
4. 음악을 들으려면 **오디오 출력 → 장치 접근 허용 → 장치 선택 → 출력 시작**을 진행하세요.
   장치가 이미 선택돼 있다면 음악 앱을 열 때에도 출력 준비를 시작합니다.
5. 출력 없이 재생을 시도했던 앱은 장치 연결 후 재생을 다시 누르거나 앱을 다시 열어야 할 수 있습니다.

## 출력과 검증 범위

연결 없이 허용하는 것은 앱 실행·설정입니다. 출력이 없으면 오디오를 재생하지 않으며,
일반 믹서·휴대폰 스피커로 자동 전환하지 않습니다. 직접 USB / 공식 비트퍼펙트 고급 모드,
원본 보존 조건 및 DSD 안전 확인은 유지됩니다.

상용 서비스의 로그인·앱 내부 재생과 물리 DAC 검증은 사용자가 제외한 범위입니다.
모든 앱·기기의 호환성을 보증하는 안정판은 아닙니다. 비밀번호·계정 토큰은 제보에 포함하지 마세요.
다운로드 파일은 첨부 `SHA256SUMS`로 확인할 수 있습니다.
