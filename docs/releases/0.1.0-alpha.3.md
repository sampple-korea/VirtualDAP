# VirtualDAP 0.1.0-alpha.3 — USB 제어 인터페이스·앱 설치 수정

Android 14 이상에서 사용하는 비루팅 알파 업데이트입니다. 이전 공개 알파와 같은 서명으로
업데이트 설치할 수 있습니다. 전체 음악 서비스 호환이나 실물 DAC 출력 검증을 마친 버전은 아닙니다.

## 이번 변경

- UAC2 USB 장치의 샘플레이트를 협상하기 전에 AudioControl 인터페이스를 점유하도록 수정했습니다.
  이전에는 오디오 스트리밍 인터페이스만 점유해 클록 제어 요청이 실패할 수 있었습니다.
- USB 제어 요청의 실패 코드와 실제로 짧게 수신한 응답을 구분합니다. 오류에는 요청·인터페이스·
  수신 길이가 포함되므로 모든 실패가 `truncated response`로 표시되지 않습니다.
- 단일 APK 안에 모듈 APK가 들어 있는 경우 설치 묶음으로 오인하던 문제를 수정했습니다.
  실제 Google Play 서비스 APK 가져오기를 확인했지만, 로그인 성공을 검증한 것은 아닙니다.

## 설치와 사용

1. 기존 공개 alpha.1/alpha.2 위에 설치하세요. 서명이 다른 개발 APK는 업데이트되지 않습니다.
   설치가 실패해도 기존 앱을 바로 삭제하지 마세요. 삭제하면 내부 앱·계정 데이터가 지워집니다.
2. **오디오 출력 → USB 접근 허용 → 이 장치로 출력**을 선택합니다.
3. 기본 USB 음량은 25%입니다. 낮은 음량에서 **도구 → 출력 소리 테스트**를 확인하세요.
4. 음악 앱은 메인 화면에서 추가합니다. 기존 앱의 로그인 정보는 복사하지 않습니다.

## 확인되지 않은 범위

- 이 수정이 SM-S938N·Moondrop FreeDSP에서 보고된 오류를 실제로 해결했는지는 아직 확인하지 못했습니다.
  계속 실패한다면 이번 버전에서 표시하는 전체 오류를 확인해야 합니다.
- Apple Music 로그인 무한 로딩과 YouTube Music 실행 문제는 아직 해결 완료가 아닙니다.
  Google 서비스 APK 설치만으로 정상 인증 환경이 완성되지는 않습니다.
- USB 기본 모드와 고급 공식 비트퍼펙트 모드는 유지합니다. 오류 시 믹서·스피커·다른 경로로
  자동 대체하지 않습니다. 음량 조절·포맷 변환이 있으면 비트퍼펙트로 표시하지 않습니다.
- 실제 출력은 동시에 하나의 스트림만 받습니다. 크로스페이드·중첩 출력은 지원하지 않습니다.
- DoP/네이티브 DSD에는 소프트웨어 음량을 적용하지 않습니다. 지원 포맷과 하드웨어 음량을 확인하세요.
- 물리 DAC, 모든 음악 서비스의 로그인·보호 콘텐츠 재생까지 검증한 최종 버전이 아닙니다.

체크섬은 함께 제공되는 `SHA256SUMS`로 확인할 수 있습니다.
문제 제보에 비밀번호나 계정 토큰을 포함하지 마세요.
