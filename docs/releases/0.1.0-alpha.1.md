# VirtualDAP 0.1.0-alpha.1 — USB 오디오 초기 공개 테스트

음악 앱 중심의 한국어 UI와 기본 직접 USB 출력 경로를 포함한 알파 버전입니다.
전체 음악 서비스 호환이 완성된 버전은 아닙니다. 루팅은 필요하지 않으며 Android 14 이상이 필요합니다.

## 사용 방법

1. 릴리즈의 APK를 설치합니다. 기존 개발용 APK와 서명이 다르면 덮어쓸 수 없습니다.
   삭제 후 설치할 경우 VirtualDAP 내부 앱·계정·설정이 함께 지워지므로 먼저 확인하세요.
2. USB DAC/이어폰을 연결하고 **오디오 출력 → USB 접근 허용 → 이 장치로 출력**을 선택합니다.
3. USB 음량은 기본 25%입니다. 낮은 음량부터 시작하세요. Android 시스템 음량과 별도로 적용됩니다.
4. **음악 앱 → 음악 앱 추가**에서 합법적으로 받은 APK/APKS를 선택하거나,
   휴대폰에 설치된 지원 대상 음악 앱을 가져옵니다. 기존 계정 데이터는 복사하지 않습니다.
5. 앱을 열어 해당 앱 안에서 설정·로그인·재생합니다. 진단, 소리 테스트, 로컬 DSD 도구는 우측 상단 **도구**에 있습니다.

## 출력 방식

- **USB 오디오 · 기본**: USB DAC에 직접 전송하고 원본 PCM 포맷을 우선 협상합니다.
  DAC 제약 때문에 변환하거나 소프트웨어 음량을 적용하면 비트퍼펙트로 표시하지 않습니다.
- **공식 비트퍼펙트 · 고급**: Android가 제공하는 정확한 포맷만 사용합니다.
  USB 연결만으로 이 API 지원이 보장되지는 않습니다. 미지원 시 안내하며 다른 경로로 바꾸지 않습니다.
- 장치 분리·오류 시 스피커나 일반 믹서로 자동 전환하지 않습니다.
- DoP/네이티브 DSD는 소프트웨어 음량을 적용하지 않습니다. 지원 DAC와 안전한 하드웨어 음량을 확인해야 합니다.

## 검증 범위와 제한

- 비루팅 에뮬레이터에서 앱 가져오기, 컨테이너 PCM 캡처, 재생 제어, 오류 복구와 UI를 검사합니다.
- 독립 배포 플레이어의 실제 WAV 재생에서 48 kHz·16-bit·스테레오 PCM을 수신하고
  좌우 테스트 신호를 확인했습니다. 실제 USB DAC에서 소리를 측정한 결과는 아닙니다.
- Apple Music·Spotify·YouTube Music 등은 지원 목표이며, 로그인·보호 콘텐츠·재생 호환성이
  모두 검증되지 않았습니다. 특히 Google 서비스가 필요한 앱은 컨테이너 안에서 로그인이 안 될 수 있습니다.
- 물리 USB 기기 검증은 하지 않았습니다. SM-S938N·Moondrop FreeDSP 동작 보증이 아닙니다.
  직접 USB 경로는 공식 API 지원 여부와 별개로 동작하도록 구현했지만, 기기별 제약이 남을 수 있습니다.
- 실제 출력은 동시에 하나의 오디오 스트림만 받습니다. 앱의 크로스페이드·중첩 재생은 지원하지 않습니다.
- 암묵적 피드백이나 제조사 전용 제어가 필요한 USB 장치, 검증되지 않은 네이티브 DSD 배열은 미지원입니다.
- 이 릴리즈는 최종 목표 달성 선언이 아닙니다. 알려진 제한이 없는 것처럼 표시하지 않습니다.

APK의 SHA-256은 함께 제공되는 `SHA256SUMS`로 확인할 수 있습니다.
버그를 보고할 때 앱 버전, Android 버전, DAC 이름과 **도구 → 진단**의 오류를 알려 주세요.
계정 비밀번호, 토큰이나 개인 음악 파일은 올리지 마세요.
