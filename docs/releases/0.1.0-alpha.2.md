# VirtualDAP 0.1.0-alpha.2 — USB 포맷 선택·음악 앱 시작 개선

Android 14 이상에서 사용하는 비루팅 알파 업데이트입니다. 전체 음악 서비스 호환이
완성된 버전은 아니며, 실제 USB DAC 출력은 아직 물리 기기로 검증하지 않았습니다.

## 이번 변경

- USB 출력 협상에서 다른 대체 설정으로 원본 포맷을 유지할 수 있는지 먼저 확인합니다.
  앞쪽 설정에서 낮은 샘플레이트만 보인다고 바로 변환하지 않습니다.
- 음악 앱이 내부에 선언한 재생 서비스를 정상적으로 찾도록 컨테이너를 수정했습니다.
  Apple Music 6.5.2의 시작 화면에서 발생한 서비스 검색 오류를 수정하고 화면 유지를 확인했습니다.
  **로그인·구독 음악 재생·DAC 출력까지 확인한 결과는 아닙니다.**
- 재생 알림, 알림 버튼과 출력 점유 오류 안내를 한국어로 바꿨습니다.
- 테스트용 음악 앱의 연속 재생 요청과 종료 처리 사이의 경합을 수정했습니다.

## 설치와 사용

1. 공개 alpha.1과 같은 서명으로 제공하므로 해당 버전 위에 업데이트 설치할 수 있습니다.
   다른 서명의 개발용 APK는 덮어쓸 수 없습니다. 삭제하면 내부 앱·계정 데이터도 지워지므로
   업데이트 실패 시 무작정 기존 앱을 삭제하지 마세요.
2. USB DAC/이어폰을 연결하고 **오디오 출력 → USB 접근 허용 → 이 장치로 출력**을 선택합니다.
3. USB 음량은 기본 25%이며 Android 시스템 음량과 별개입니다. 먼저 낮은 음량을 확인하세요.
4. **음악 앱**에서 APK/APKS를 추가하거나 휴대폰의 지원 대상 앱을 가져옵니다.
   기존 앱의 계정 데이터는 복사하지 않습니다.
5. 진단, 출력 소리 테스트와 로컬 DSD는 우측 상단 **도구**에 모았습니다.

## 출력과 남은 제한

- 기본 USB 모드는 원본 PCM 포맷을 우선합니다. 필요한 변환이나 소프트웨어 음량 조절이 있으면
  비트퍼펙트로 표시하지 않습니다. 고급 공식 비트퍼펙트 모드는 Android가 제공하는 정확한 포맷만 받습니다.
- 오류·장치 분리 시 일반 믹서/스피커나 다른 출력 모드로 자동 대체하지 않습니다.
- 실제 출력은 동시에 하나의 스트림만 받습니다. 크로스페이드·중첩 재생은 지원하지 않습니다.
- DoP/네이티브 DSD에는 소프트웨어 음량을 적용하지 않습니다. DAC 지원과 안전한 하드웨어 음량을 확인하세요.
- 제조사 전용 제어·암묵적 피드백이 필요한 USB 기기와 미검증 네이티브 DSD 배열은 제한될 수 있습니다.
- SM-S938N·Moondrop FreeDSP의 직접 USB 재생을 보증하는 릴리즈가 아닙니다.
- Apple Music·Spotify·YouTube Music 등 모든 서비스의 로그인·보호 콘텐츠·재생은 아직 검증되지 않았습니다.
  특히 컨테이너 안의 Google 서비스 의존성이 남아 있습니다.
- 이 업데이트는 최종 목표 달성 선언이 아닙니다. APK 체크섬은 함께 제공되는 `SHA256SUMS`로 확인하세요.

문제 제보에는 앱 버전·Android 버전·DAC 이름과 **도구 → 진단**의 오류를 포함해 주세요.
계정 비밀번호나 토큰은 보내지 마세요.
